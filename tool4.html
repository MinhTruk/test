Thông tin định dạng

.rxdata — RPG Maker XP. Thường lưu bằng Ruby Marshal.
.rvdata — RPG Maker VX. Thường lưu bằng Ruby Marshal.
.rvdata2 — RPG Maker VX Ace. Thường lưu bằng Ruby Marshal.
Giới hạn hiện tại: Công cụ này nhận diện header và phân tích token ở mức byte. Nó chưa giải tuần tự hóa toàn bộ đồ thị object RGSS, chưa hỗ trợ sửa object rồi Marshal.dump trở lại. Không thể dùng Hex Viewer để sửa trực tiếp save an toàn.

Ruby Marshal có object links, symbol links, class metadata và các kiểu object riêng. Chỉ thay byte hoặc chuyển thành JSON thường sẽ làm mất tham chiếu và có thể khiến game không tải được save.
